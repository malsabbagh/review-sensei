# Trademark usage policy

Project: ReviewSensei  
Last updated: 2026-09-16  
Related: [issue #89](https://github.com/malsabbagh/review-sensei/issues/89),
[`docs/ownership-and-licensing.md`](docs/ownership-and-licensing.md)

This policy describes how to refer to the ReviewSensei name and logo so that
people can identify the official project without confusion. It is **not** a
trademark registration, a worldwide clearance opinion, or a change to the MIT
(or other) copyright licenses that apply to files in this repository.

Copyright permissions for software and image files remain governed by their
applicable licenses. This file does not withdraw those permissions. See
[`LICENSE`](LICENSE) and [`docs/ownership-and-licensing.md`](docs/ownership-and-licensing.md).

## Copyright licensing is separate

The MIT License (and CC0-1.0 for the synthetic evaluation corpus) control
**copyright** in covered materials. Trademark rules control **how you use the
name and logo to identify origin**. Receiving a copy of the Software under MIT
does not grant permission to imply official status, sponsorship, or endorsement
where that would be misleading.

## Branding permission contact

For permission requests about logos, co-branding, or other uses not covered by
the permitted references below, open a public GitHub issue in
[malsabbagh/review-sensei](https://github.com/malsabbagh/review-sensei/issues)
describing the intended use, or contact the maintainer listed in
[`CODEOWNERS`](CODEOWNERS) (`@malsabbagh`). Do not include credentials or private
customer data in the request.

## Permitted uses

Without additional permission, you may:

- Refer to ReviewSensei by name in accurate, descriptive statements (for
  example, that software is compatible with, integrates with, or was evaluated
  using ReviewSensei).
- Attribute forks, distributions, and documentation to the upstream project
  when that attribution is truthful.
- State compatibility or derivation in a non-misleading way, such as:
  **“Acme Reviewer, based on ReviewSensei.”**
- Reproduce logos or word marks **as required by an applicable copyright
  license notice** when redistributing files that already contain them, or when
  linking to the canonical project channels above.
- Use the name in academic, journalistic, or comparative discussion where
  trademark law already permits nominative or descriptive reference.

These permissions do **not** restrict MIT rights to use, modify, fork,
redistribute, commercially reuse, or self-host the covered Software, subject to
MIT’s notice conditions.

## Uses that need care or permission

Do **not**, without prior written permission from the rights holder:

- Present a fork, SaaS, distribution, or GitHub App as the **official**
  ReviewSensei project, release channel, or sponsored product when it is not.
- Use the name or logo in a way that suggests endorsement, certification, or
  partnership by Mohamad Alsabbagh or the ReviewSensei maintainers when none
  exists.
- Use confusingly similar branding as the primary product name for an unrelated
  offering in a way likely to mislead users about origin.
- Alter the logo primarily to suggest official affiliation while changing
  behavior or security boundaries.

Truthful statements that you offer a competing or alternative tool, or that you
self-host ReviewSensei under MIT, are not banned by this policy.

## Forks, redistribution, and commercial reuse

This trademark policy does **not** add an anti-fork, anti-SaaS, or
non-commercial condition to the MIT License. You may fork and commercially reuse
MIT-covered code under MIT’s terms. Separately, avoid brand presentations that
would reasonably confuse users into thinking your offering is the official
ReviewSensei distribution or hosted service.

## Logo and image file licenses

Copyright licenses that already apply to logo and website asset files continue
to apply. This policy does not relicense those files. Any prospective change to
asset copyright licensing requires a provenance review and an explicitly scoped,
maintainer-approved decision recorded in the repository.
