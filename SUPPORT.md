# Support

ReviewSensei is an open-source review engine that runs in your own repository;
there is no hosted backend or private support queue.

For questions, troubleshooting, reproducible bugs, documentation gaps, and
feature proposals:

1. Read [`docs/community.md`](docs/community.md) for governance and triage
   boundaries.
2. Search existing [GitHub Issues](https://github.com/malsabbagh/review-sensei/issues).
3. Open the matching [issue template](.github/ISSUE_TEMPLATE/) and provide a
   minimal, sanitized reproduction.

Include the ReviewSensei version, Python version, operating system, installation
method, provider type, configuration with secrets removed, and command output
with private source removed. Do not include credentials, private diffs, private
source code, personal data, or raw provider responses. Maintainers cannot
inspect private repositories or recover data sent to a provider.

For suspected security vulnerabilities or private/serious concerns, follow
[`SECURITY.md`](SECURITY.md) and use its private reporting route instead of
opening a public issue. The [Code of Conduct](CODE_OF_CONDUCT.md) also explains
the private escalation path for conduct concerns.
